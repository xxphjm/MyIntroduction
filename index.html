我叫黃建銘，目前就讀高雄科技大學智慧商務系。 最早接觸程式，其實是在高職時期。那時候和幾個朋友一起參加網頁設計比賽，我們用最基礎的 HTML 和 CSS，一邊摸索一邊做，最後還拿到了名次。也就是從那次開始，我對網頁開發產生了很大的興趣。 上了大學之後，我開始系統性學習程式，接觸了 Python、JavaScript、PHP，也慢慢理解前後端怎麼串接、怎麼透過 API 把系統整合起來。我特別對前端很有興趣，目前也在持續學習像 Angular、Vue 這類框架，同時也不排斥往後端延伸，希望讓自己的技術更完整。 到了碩士階段，我把重心放在 AI 領域，有機會參與智慧零售相關計畫，負責數據分析與銷售預測模型的建立。這段經驗讓我開始思考，怎麼把數據真的轉換成對企業有幫助的決策。 除了課業之外，我也自己研究生成式 AI 和提示工程，並在 GitHub 上做了一些小專案，像是把 AI 功能整合進 LINE 和 Discord，讓它可以自動生成內容或協助寫程式。雖然規模不大，但這些實作讓我更清楚 AI 在實務上的可能性。 一路走來，我發現技術變化真的很快，所以我也一直提醒自己要持續學習、保持敏銳，讓自己不只是會用工具，而是能跟著技術一起成長。
